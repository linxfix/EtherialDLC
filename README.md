# Etherial

**Etherial** — клиентский мод для Minecraft. Релизы публикуются в разделе [Releases](https://github.com/EtherialDLC/EtherialDLC/releases).

| | |
|---|---|
| Версия | `BETA1.21.11` |
| Minecraft | `1.21.11` |
| Загрузчик | Fabric (`>=0.17.0`) |
| Зависимости | Fabric API |
| Java | `21+` |
| Автор | Remila |

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/use/installer/) для Minecraft `1.21.11`.
2. Установи [Fabric API](https://modrinth.com/mod/fabric-api).
3. Скачай `Etherial-BETA1.21.11-plain.jar` из последнего релиза.
4. Помести файл в папку `.minecraft/mods`.

## Загрузка

Все версии доступны на странице релизов:

```
https://github.com/EtherialDLC/EtherialDLC/releases
```
